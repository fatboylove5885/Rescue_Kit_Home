Security & hosting notice

This page is hosted on public GitHub Pages. Its contents, links, image names, research notes, and operational counts can be viewed by anyone with the URL. The private image library stays in Google Drive, and no API keys, billing details, user emails, access tokens, or private screenshots are published here. “Noindex” reduces search indexing; it is not authentication.

Metricool scheduling is verified separately from actual Pinterest publication. This dashboard never calls a private Metricool API from a visitor's browser.

How to interpret the numbers

“Planned” = research brief saved; “Generated” = original image file confirmed; “Queued” = Metricool accepted the post; “Published” = Metricool or Pinterest reported published. They are different states and must never be combined into an unverified success claim. Archived snapshots preserve historical counts. The GitHub Action updates this data hourly, but private provider states change only when the connected scheduling guard writes an updated receipt.
