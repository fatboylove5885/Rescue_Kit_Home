# What's For Eats — Pinterest reference library: evidence-based creative standards

**Research precedes visual generation on EVERY local date (America/Detroit).**

- Daily 07:00: Analyze verified @dayecreations pins. Browse actual Pinterest images. Archive each observed competitor Pinterest pin image (not just a text link) privately to the dated **Google Drive/Pinterest Reference Library/YYYY-MM-DD/Competitor Observed/** folder, add canonical source URL, observation, keyword, and observed/public performance facts only.
- Store existing What’s For Eats examples in **Brand Style Examples**, not in `Own Verified Winners 500+`. The original cartoon/flat-vector designs are rejected.
- Each competitor visual is a *candidate* unless performance is supported by independently verifiable public evidence. Never invent competitors' private saves/clicks/impressions. Avoid copying reference assets or distinctive compositions verbatim. Preserve the appealing benefit and general design principle.
- Review the user's actual pins. Do not promote any own pin into **Own Verified Winners 500+** until **at least 500 verifiably measured impressions**. Once over that threshold, evaluate save rate and outbound CTR against a 30-day time/topic-normalized cohort (ideally similar age and impression range), not cumulative views. For a conservative promotion require at least five combined save+click actions and `(saves + outbound_clicks) / impressions >= 1.30 × cohort median`. If median unavailable, keep in Pending even if total views high. Do not promote just because an image is pretty.
- For clear underperformers **after at least 500 impressions and enough observation time**: if both save rate and outbound CTR are below comparable 30-day cohort medians, retire the execution from the winning pool; keep provenance and experiments for learning. Never delete published pins just because early engagement is weak. Review again with larger samples; 500 impressions is the *minimum screening threshold*, not proof of long-term success.
- Test one meaningful factor per experiment: photo composition, headline, offer, contrast, topic, or CTA. Change what is empirically poor; retain repeated wins; prevent near-duplicate content.
- Produce nine distinct new ORIGINAL first-party AI-generated food images after today's manifest has been written and references archived. **Do not substitute old site photos or generic drawings.** Design must fit actual linked articles. Generate in 1024x1536 and assemble 1000x1500 pins with legible typeset headlines/CTAs.
- The GitHub publisher runs at 08:15 only if today's research manifest exists and at least 3 competitor images have been archived. Requires a user-configured GitHub `OPENAI_API_KEY` secret for paid first-party image API access. Missing key or missing research is a **hard stop**, never a license to recycle earlier imagery. No unattended cost occurs without the user's key.
- RSS updates trigger Pinterest import on Pinterest's timetable (up to 24-48h), not exact posting times. Metricool Free has limited scheduling capacity and is not a 9-per-day long-term channel. Separate statuses: research saved / original images generated / feed updated / Pinterest imported / published / performance verified.

Private image references reside in Google Drive; the public GitHub repository contains only text provenance and generated original images, not other creators' copyrighted screenshots.
